
# Parth Rishi – Resume Website

A personal resume website built using **HTML and CSS** as part of my midterm project. The website showcases my professional profile, work experience, education, skills, and contact information in a clean and structured layout.

## Features
- Personal profile and introduction
- Contact information
- Professional skills and languages
- Work experience and responsibilities
- Educational background
- Profile photograph
- Font Awesome icons and Google Fonts

## Technologies Used
- HTML5
- CSS3
- Google Fonts (Lato & Poppins)
- Font Awesome 6

## Project Structure

```text
Resume-Website/
│
├── index.html
├── resume.css
├── photo.jpg
└── README.md
```

## How to Run

1. Clone this repository:
   ```bash
   git clone YOUR-REPOSITORY-URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
